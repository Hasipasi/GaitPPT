# GaitPPT: Parallel Part-based Transformer for Gait Recognition from Lidar Point Clouds

**BMVC 2026** · Balázs M. Bódis†, Gergő Nagy†, Csaba Benedek († equal contribution)

HUN-REN Institute for Computer Science and Control · Pázmány Péter Catholic University, Faculty of Information Technology and Bionics

**[Project page](https://hasipasi.github.io/GaitPPT/)** · **[Paper (PDF)](https://hasipasi.github.io/GaitPPT/static/GaitPPT_BMVC2026.pdf)** · **[Video](https://hasipasi.github.io/GaitPPT/#video)** · **[Poster](https://hasipasi.github.io/GaitPPT/static/GaitPPT_poster_BMVC2026.pdf)**

GaitPPT-Base reaches 94.23% cross-view Rank-1 on SUSTech1K with 2.87 M parameters (+1.53 over LidarGait++ with 34% fewer parameters), and GaitPPT-Large reaches 85.74% Rank-1 on FreeGait.
